# دانلود و به‌روزرسانی آزادبرد

در حال حاضر انتشار عمومی موجود نیست. این راهنما برای نخستین انتشار و نسخه‌های بعدی آماده شده است.

## انتخاب فایل

**arm64** انتخاب مناسب اغلب گوشی‌های جدید است. اگر مطمئن نیستید، **Universal** را انتخاب کنید. این دو فایل نسخه‌های متفاوت محصول نیستند؛ بسته‌بندی معماری‌های پردازنده متفاوت است. هر دو به اندروید ۷ یا بالاتر نیاز دارند.

فایل APK را تنها از [Releases رسمی](https://github.com/TIR3D4/AzadBird/releases) بگیرید. فایل‌های خودکار **Source code (zip/tar.gz)** در پایین Release، آرشیو مستندات همین مخزن هستند و برنامهٔ قابل‌نصب نیستند.

## نصب

پس از دانلود، فایل APK را باز کنید. اگر اندروید اجازه خواست، نصب از همان مرورگر یا مدیر فایل را مجاز کنید. به‌روزرسانی روی نسخهٔ قبلی نصب می‌شود؛ حذف اپ ممکن است اشتراک‌های ذخیره‌شده را از بین ببرد. ناسازگاری امضا را با حذف اپ دور نزنید.

## بررسی SHA-256

در ویندوز PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\AzadBird-Android-arm64.apk
```

مقدار خروجی باید با سطر همان فایل در `SHA256SUMS.txt` انتشار یکسان باشد. نام فایل دانلودی را در دستور جایگزین کنید. هش، تغییر یا خرابی فایل را مشخص می‌کند؛ بررسی امضای نصب را جایگزین نمی‌کند.

## انتخاب نسخه

نسخهٔ عادی برای استفادهٔ عمومی است. **Pre-release** برای آزمون است و ممکن است محدودیت‌های بیشتری داشته باشد؛ توضیحات همان انتشار را بخوانید. نصب نسخهٔ قدیمی‌تر ممکن است توسط اندروید رد شود. برای بازگشت نسخه، داده‌ها را خودکار پاک نکنید.
